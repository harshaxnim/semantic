Verifier soundness

The thesis rests on verifiers that never accept a wrong answer, so they are tested first. Each reference answer must be accepted. Each mutated answer (one step changed, dropped or swapped) is verified. Blocksworld verdicts are also cross-checked against an independent STRIPS simulator.
